# Telegram-бот расписания группы 4117

Бот показывает расписание на сегодня или на все даты выбранного дня недели. Расписание хранится в `schedule.json`: у каждой пары указаны номер дня недели (понедельник — `0`), время, список дат в формате `ДД.ММ`, предмет, тип занятия, аудитория и корпус. Год расписания задаётся в поле `year`.

## Запуск

Нужен Python 3.9 или новее. Создайте бота через BotFather, откройте файл `.env` и вставьте токен в строку `TELEGRAM_BOT_TOKEN` вместо `ВСТАВЬТЕ_ТОКЕН_СЮДА`. Затем запустите:

```bash
python3 bot.py
```

Чтобы изменить расписание, отредактируйте записи в `schedule.json`. Кнопка конкретного дня недели покажет занятия на все перечисленные для этого дня даты. Длинное расписание бот отправляет несколькими сообщениями.
